
# OpenAI Chatbot using Streamlit

## Project Description

This project is an interactive AI chatbot built using Python,
Streamlit, and the OpenAI API.

Users can enter their own OpenAI API key through the sidebar,
select an OpenAI model, and interact with the chatbot.

## Features

- OpenAI API key input through the sidebar.
- API key required before chatting.
- Multiple OpenAI model options.
- Interactive chatbot interface.
- Conversation history using Streamlit session state.
- Clear chat functionality.
- Error handling for invalid API keys and API errors.

## Technologies Used

- Python
- Streamlit
- OpenAI API
- GitHub
- Streamlit Community Cloud

## Installation

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder:

   cd openai-streamlit-chatbot

3. Create a virtual environment:

   python -m venv venv

4. Install dependencies:

   pip install -r requirements.txt

5. Run the application:

   streamlit run app.py

## Usage

1. Open the application.
2. Enter your OpenAI API key in the sidebar.
3. Select your preferred OpenAI model.
4. Enter a message in the chat input.
5. Receive an AI-generated response.

## Deployment

The application can be deployed using
Streamlit Community Cloud.
